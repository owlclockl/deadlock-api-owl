# Локальный запуск на Windows 10/11 x64

1. Используйте Windows 10/11 с поддержкой WSL2 и включённой виртуализацией.
   Docker Desktop заранее устанавливать не обязательно: пункт 1 установит его через winget.
2. Распакуйте **весь** архив в обычную папку. Не запускайте батник прямо из ZIP.
3. Дважды нажмите `Запустить.bat` в корне и выберите пункт 1 (или Enter).
4. После подготовки откроется http://localhost:3000.

Первый запуск скачивает Node, Rust, зависимости и собирает WASM: нужны интернет,
несколько ГБ свободного места и время. Это исходный дистрибутив с автоматической
сборкой, **не готовый автономный EXE**. Следующие запуски используют кеш Docker.
При выборе пункта 1 запускатель сам устанавливает Docker Desktop через winget,
при необходимости запускает установку WSL2 и ожидает запуска Docker. Windows
может запросить права администратора; Docker может показать условия лицензии
и начальную настройку — их нужно пройти самостоятельно.

Если нужна перезагрузка, запускатель сообщит об этом и добавит одноразовое
продолжение в `HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce`.
Перезагрузите ПК самостоятельно: после входа настройка продолжится. Не перемещайте
папку до завершения настройки. Автоматической принудительной перезагрузки нет.
Если winget отсутствует, откроется Microsoft Store для установки «Установщика
приложений»; после его установки повторите пункт 1. Включение виртуализации
в BIOS/UEFI, если требуется, нужно выполнить самостоятельно.

Чтобы отменить запланированное продолжение, выполните в PowerShell:
`Remove-ItemProperty HKCU:\Software\Microsoft\Windows\CurrentVersion\RunOnce -Name DeadlockOwlSetup -ErrorAction SilentlyContinue`.
Автоматическая установка ничего не делает при выборе пунктов 2–5.

## Меню

- 1 — собрать/запустить сайт и открыть браузер.
- 2 — остановить сайт (данные браузера не удаляются).
- 3 — посмотреть журналы (Ctrl+C для выхода).
- 4 — открыть выбранную вами папку игры в Проводнике. Путь можно найти в Steam →
  Deadlock → Свойства → Установленные файлы → Обзор.
- 5 — запустить установленный Deadlock через Steam (App ID 1422450).

## Границы доступа

Сайт работает локально, но получает данные из публичного https://api.deadlock-api.com.
Нужен интернет; лимиты, подписки, Steam/Patreon-авторизация и ограничения API не обходятся.
Некоторые внешние функции (например, OAuth с разрешёнными callback-адресами и AI с
серверными ключами) могут быть недоступны на localhost. Полная идентичность боевому
сайту не гарантируется.

Контейнер не получает доступ к диску Windows и не монтирует папку игры. Пункт 4
открывает Проводник, пункт 5 — Steam. Это не чтение памяти игры, не автоматическое
редактирование конфигурации и не интеграция игровых файлов с сайтом. Ничего из
выбранной папки автоматически не загружается в API. Для импорта файлов используйте
выбор файла в тех разделах сайта, где он предусмотрен.

Сайт слушает только локальный порт 3000. Если он занят, остановите другое приложение.
При ошибке сохраните текст из окна или выберите пункт 3. Закрытие окна батника
не останавливает контейнер — для этого есть пункт 2. Для полного удаления образа:
`docker compose -f local/windows/compose.yaml down --rmi local` из корня архива.

Этот пакет использует Vite dev server для локального SSR, а не Cloudflare deployment.
Он предназначен для личного локального использования, не для публикации в интернет.
